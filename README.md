# Java Quiz

A simple Java console application where you can test your knowledge of Java through multiple-choice questions.

## Features

- Three difficulty levels: Easy, Medium, and Hard
- Multiple-choice questions about Java fundamentals
- Automatic answer checking and score calculation
- Statistics showing correct and incorrect answers
- Percentage calculation for each completed quiz
- Best score tracking based on percentage
- Option to display all available questions

## What I Practiced

I built this project to practice Java programming and improve my understanding of fundamental programming concepts.

While working on it, I practiced:

- Arrays and two-dimensional arrays
- Methods and parameters
- Loops and conditional statements
- Switch expressions
- User input and basic input validation
- Calculations and score tracking

## Technologies

- Java
- IntelliJ IDEA

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure Java is installed.
4. Run `Main.java`.

## Notes

The best score is tracked while the application is running. Scores are not saved permanently after the program closes.
